# Restaurant Menu

A simple digital restaurant menu created using **HTML** and **CSS**.  
Displays sections like *Starters*, *Main Course*, *Desserts*, and *Drinks*, laid out neatly using flexbox/grid, with a warm color theme.

---

## 🧩 Features

- Clean, responsive layout using CSS Flexbox
- Card-style design for menu items
- Hover effects for interactivity
- Warm, appetizing color palette
- Easy to extend / customize (add more items, change styling)

---

## 📁 Project Structure

restaurant_menu/
│
